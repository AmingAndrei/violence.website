The VENOM project is a secret project run by the [[pale|Pale]].
# .design
<div class="bestiary-divider"></div>

The main VENOM project facility is located near the entrance to [[city_zero|City Zero]]'s foundation.
# .specs
<div class="bestiary-divider"></div>

The goal of the VENOM project is the cloning of very powerful or versatile [[hybrids]], usually [[ultraviolet|Ultraviolet]] Operators. This is done in case the original [[hybrids|hybrid]] dies, since the chance of encountering an individual with the same ability is close to non-existent. The resulting clone is an individual with the same genetic blueprint and ability as the original; however, other traits, such as personality or sex, may vary.

As of 10 [[timeline|AV]], the only successful clone of the project is Jacquelyn Ren.
