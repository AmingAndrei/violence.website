The Radio Computer Network is an interconnected computer network utilising radio waves to communicate between devices. Individual units are called Radio Computers, or RCs for short.
# .design
<div class="bestiary-divider"></div>

Standard RCs are composed of a main unit that comes integrated with a screen and keyboard. More advanced models come with just the main unit, allowing the user to connect their own screen and keyboard. While most tasks can be done through the keyboard alone, a 'bug' pointing device is considered a standard accessory. Each RC comes integrated with a modem.

The master server of the entire Network is housed within the Spine, and is composed of an extremely compact matrix of silicon lattices that store data as etched micro-markings and light signals, suspended in a vacuum. Additional relays are used to better coordinate the link between the master server and the RCs.
# .specs
<div class="bestiary-divider"></div>

The master server has a storage capacity of ~100 EB, its structure allows the processing of complex data within seconds and make unintentional data loss impossible. To connect to the Radio Computer Network and the master server, each user must pay a subscription, and more expensive subscriptions allow the user to establish a better connection between the master server and their RC's modem.

RCs themselves have very little processing power and storage. Instead, everything is handled by the master server, to which every RC is connected through a complex sequence of multi-layered, encrypted radio waves. All digital applications are also stored and run on the master server, then broadcast to individual RCs. As a structural consequence, a majority of computer games are multiplayer, to lower processing costs.

Due to it reliance on radio waves, the Radio Computer Network is especially affected by [[steel_sharks|Steel Sharks]], which can intercept the radio signal and modify it however they desire, which can have all sorts of effects depending on what data the signal was carrying. Types which have the ability to interact with electronic devices can also interact with the Network through RCs. The [[black_box|Black Box]] can cause internal structural damage in the master server as a result of its erasure effect.
